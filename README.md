# Alien Conquest — Stake front end

This folder is the game screen to upload to Stake Engine.

`index.html` is the file Stake looks for. Do not rename it.

## Upload

1. On GitHub, click **Code**, then **Download ZIP**.
2. Unzip it.
3. Open your game on Stake Engine and go to **Files**.
4. Choose **Import Files**, then **Front End**.
5. Select the unzipped folder. `index.html` must be directly inside it.
6. Click **Publish Game**, then **Front End**.
7. On the **Developer** page, start a session and launch the game.

The math books are not in this folder. Upload those separately.
